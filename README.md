# Cognifyz Software Development Internship — C++

This repository contains all six assigned Software Development internship tasks implemented in **C++**.

## Project Structure

### Level 1
- Task 1: Text-Based Number Guessing Game
- Task 2: Number Pattern Generator

### Level 2
- Task 3: CRUD Task Manager using a `Task` class
- Task 4: Temperature Converter

### Level 3
- Task 5: Persistent CRUD using text-file storage
- Task 6: Interactive Web Scraper using C++ and the system `curl` command

## Requirements

- C++17 compatible compiler (g++, MinGW-w64, or Visual Studio C++)
- Windows 10/11 includes `curl.exe` for Task 6

## Compile and Run

```powershell
g++ main.cpp -std=c++17 -o app.exe
.\app.exe
```
